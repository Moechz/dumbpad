# Changelog

All notable user-visible changes to the DumbPad TOS application package.

## 1.0.5-1 — 2026-11-14

### Added
- First release. DumbPad (`dumbwareio/dumbpad:1.0.5`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8134 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/dumbpaddocker/`.
